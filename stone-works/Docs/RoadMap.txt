STONEWORKS — ROADMAP
====================

Purpose
-------
This is the implementation roadmap. The GDD defines intended gameplay; TechnicalArchitecture.txt defines system ownership and communication; GodotProjectStructure.txt defines physical file organization.

Status labels:
- DONE = defined/decided or completed where explicitly stated
- NEXT = immediate implementation target
- TODO = planned implementation work
- OPEN = design decision still required

12. ARCHITECTURE RULE
---------------------

Do not create the entire planned script tree just because it is documented.
Implement the smallest useful system for the current roadmap step, while preserving the documented ownership boundaries.

The three baseline managers remain intentional architecture components:
- ResourceManager
- WorkerManager
- MachineManager

Do not add additional generic managers unless a concrete lifecycle/ownership requirement justifies one.
